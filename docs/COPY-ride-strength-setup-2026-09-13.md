## The screen Run + Strength has that this path does not

Run + Strength has a **Build focus** screen between the endurance screen and Your week. Its subtitle
reads: "These are your hypertrophy lifts and super sets based on the equipment you have. You can swap
on the day or adjust now for the plan." It lets the athlete pick the accessory lifts.

The Ride + Strength path skips it, because the path Michael named has no such step. p278 still prints
three accessory cells (focused pull, focused push, accessory lower), so this plan builds them from the
default picks for the athlete's equipment. The athlete can still swap on the day. Open question: should
Ride + Strength get the Build focus screen too?
